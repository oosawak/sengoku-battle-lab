## 2. 地形パイプライン（実証済み）

- 取得: 地理院標高タイル PNG形式 `https://cyberjapandata.gsi.go.jp/xyz/dem_png/{z}/{x}/{y}.png`（DEM10B、z14まで）
- 復号: `x = R*65536 + G*256 + B`、`x = 2^23` は無効、`x > 2^23` は `x - 2^24`、標高 `h = x * 0.01` m（地理院「標高タイルの詳細仕様」）
- 処理（`scripts/fetch_dem.py`）: 中心タイルを含む3×3タイルを接合 → 中心512×512px（約3.9km四方）を切り出し → 4px平均で128×128グリッドへ縮小 → `data/<battle>.json` に保存。ブラウザ側はこのJSONだけを読むので、スマホでも通信は軽い。
- 縦の誇張（試作値）: 実寸では起伏比が 人取橋 158m/3.9km、摺上原 360m/3.9km と小さい。既定の誇張率は 人取橋 ×6、摺上原 ×3.5 とし、モック上でスライダー調整できるようにする。
- 川・道の線: 本人の OSMCityScout（「街並みスケッチ 3D × INKBOUND」、MIT・本人著作）と同じ方式に切り替えた（2026-11-01）。ブラウザ実行時に Overpass API から waterway／highway／natural=water を取得し、取得先は private.coffee → VK Maps → overpass-api.de の順にフォールバック、結果は localStorage に24時間保存。失敗時は模式線に落とす。座標変換（緯度経度→DEMグリッド）の計算は Node で検証済み（中心点が63.5,63.5、1km北で y が約31減、1km東で x が約33増）。
  - なお Muse の実行環境からは Overpass への POST がプロキシで 406 になる等、サーバー側取得が通らなかった（2026-11-01実測）。だからこそ取得はブラウザ側（OSMCityScout方式）が正解、という確認にもなった。
- 2D代替: 同じ標高グリッドから等高線＋陰影を Canvas 2D で描く表示を併設する（three.js が読めない環境・軽さ優先のときの受け皿。当初の前提どおり）。

## 4. 采配と危険度（方針メモ004の実装案）

### 実効値
- 実効武勇 = 基本武勇 ＋ 年齢補正（決定002: 年齢で下がった分は本来知略＝采配へ回る。合戦では「身体を使う判定」に年齢不利） ＋ 健康補正（健やか 0／不調 −8／重篤 −20） ＋ アイテム補正（一時的に往年の武勇まで戻せる、決定002）
- 采配力 = 知略（決定002で「采配」は新能力にせず知略が担う）

### 危険度（0〜100、試作式）
```
危険度 = 合戦基礎（人取橋 35／摺上原 35。摺上原は敵地・防衛側の敵優勢 +10 も加える）
+ 役目危険（本陣 0／正面 15／退却援護 15／側撃 20／先陣 25／殿 30）
+ 敵優勢度（兵力比から: 人取橋の伊達側 +20、摺上原の伊達側 0 など合戦ごとに設定）
- 実効武勇 × 0.25
- 采配力 × 0.15
- 健康補正（不調 +8／重篤 +20）
```
表示帯: 〜29「低」／30〜54「中」／55〜74「高」／75〜「極高」。選択肢には必ず帯と内訳の要点（役目・健康など）を出す（メモ004「事前に目安が見える」）。

### 計算例（試作式に実データを入れたもの）
- 政宗・人取橋「自ら先頭に残る」: 35 + 25（先陣） + 20（敵優勢） − 72×0.25 − 86×0.15 = **49.1 → 中**（上限寄り。既存イベントの「寿命 −2」は健康低下へ読み替え予定）
- 成実・人取橋「殿を務める」: 35 + 30（殿） + 20 − 78×0.25 − 82×0.15 = **53.2 → 中**（上限寄りで、討死判定の門にかかる）。史実で殿の鬼庭良直が討死したのは72歳という年齢も大きく、年齢補正が効く人物では危険度がさらに上がる想定。
- 成実・摺上原「側撃」: 35 + 20（側撃） + 10（敵優勢） − 78×0.25 − 82×0.15 = **33.2 → 中**。手柄は最大級だが危険は中——地形を知っている（偵察済み）側の割引 −10 を入れると 23.2「低」になり、「知っている地形は危険を下げる」実感が出る。
- 調整の記録（2026-11-01）: 初版の式で摺上原が一律「低」に沈む問題が計算検証で見つかり、合戦基礎と敵優勢を上記の値に直した。人取橋も殿が討死の門（50）にかかるよう基礎を30→35に上げた。

### 結果分岐（敗北＝死、にしない）
危険度帯ごとに抽選の重みを変える（数値はすべて試作値、要プレイ検証）:
- 討死: 危険度が50以上のときだけ発生しうる。目安 `max(0, (危険度−38) × 0.35)%`、上限35%。
- 負傷: 健康 −20〜−40（決定003の健康管理へ接続）。
- 敗走: 評判 −、命は助かる。
- 捕虜: 敗北側で、討死判定を外れた場合の一部。分岐はメモ004どおり — ①身代金／人質交換で帰還（貫の支出＋数か月経過）②捕えた側への仕官（所属変更、一生の分岐）③幽閉（年月経過＋敵将との関係イベント）④処刑はごく稀（高仇敵関係など条件付き、2%未満）。
- 手柄と危険の対応: 期待評判の大きい采配ほど役目危険を高く置く、を原則とする。
