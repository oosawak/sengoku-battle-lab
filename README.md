# sengoku-battle-lab

『奥羽一生録』（戦国人生シミュレーション）の合戦まわりを、本体の開発から切り離して実験する場所です。本体リポジトリ sengoku-life-sim には統合していません。統合するかどうかは別途判断します。

## トラックA: 3D地形の布陣図＋采配（track-a/）

- 国土地理院の標高データ（DEM10B）を three.js で線画表示し、采配だけを選ぶ合戦シーンの試作
- 試作の合戦: 人取橋の戦い（1585）／摺上原の戦い（1589）。合戦切替・3D／2D切替・視点（政宗／成実）・危険度の事前表示・結果分岐（討死／負傷／捕虜／生還）まで触れます
- 設計の正本メモ: `track-a/DESIGN.md`（危険度式・結果分岐・本体との接続口の案）
- 地形データの生成: `track-a/scripts/fetch_dem.py`（地理院標高タイルPNG → 128×128グリッドJSON）
- three.js は `track-a/vendor/` に同梱（MITライセンス、three@0.160.0）。CDNには依存しません

公開ページ: https://oosawak.github.io/sengoku-battle-lab/track-a/

## トラックB: SRPG風の戦術マップ（未着手）

部隊をマス目で動かす独立試作を、トラックAとは混ぜずに置く予定です。

## データとクレジット

- 標高データ: 国土地理院・地理院タイル（基盤地図情報 数値標高モデル DEM10B）
- 合戦・人物の骨格は史実をもとにし、文章・プログラム・配置はオリジナルです（配置は模式図）
